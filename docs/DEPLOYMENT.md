# VOTR Deployment Guide

## Backend (Render)

### Quick Deploy

1. Push your code to GitHub
2. Go to [Render Dashboard](https://dashboard.render.com) → New → Blueprint
3. Connect your GitHub repo (votr)
4. Render will detect `render.yaml` and create:
   - Web service (votr-api)
   - PostgreSQL database (votr-db)
5. In the votr-api service, add `GOOGLE_CIVIC_API_KEY` (Dashboard → votr-api → Environment)
6. Deploy will run migrations and start the server

### Post-Deploy

- Your API URL: `https://votr-api-XXXX.onrender.com`
- Health check: `https://votr-api-XXXX.onrender.com/health`
- Update mobile `EXPO_PUBLIC_API_URL` or production build to use this URL

### Custom Domain

To use `api.votr.app`:
1. Add custom domain in Render (votr-api → Settings → Custom Domains)
2. Add CNAME record: `api.votr.app` → `votr-api-XXXX.onrender.com`

## Mobile (Expo / EAS)

For production mobile builds:

```bash
cd mobile
# Set production API URL
echo "EXPO_PUBLIC_API_URL=https://your-api-url.onrender.com/api" > .env

# Build for iOS/Android (requires EAS account)
npx eas build --platform all
```

## Environment Variables (Production)

| Variable | Required | Notes |
|----------|----------|-------|
| DATABASE_URL | Yes | Auto-set by Render when linked |
| JWT_SECRET | Yes | Auto-generated by Render (or set manually) |
| GOOGLE_CIVIC_API_KEY | Yes | Add in Render Dashboard |
| NODE_ENV | - | Set to `production` |
| OPENAI_API_KEY | No | For bias detection |
| HUGGINGFACE_API_KEY | No | For ML features |
